# Provider Integration

Provider Integration 记录具体 Provider 包。这里可以写 Provider 特定认证模式、字段、工作流和示例。

Core 文档解释 AtlasClaw 如何加载 Provider 并执行共享运行时规则；Provider 文档解释具体集成能做什么。

## 当前 Provider {#included-providers}

当前详细覆盖 SmartCMP Provider。其他 Provider 在契约和流程稳定后可加入本章节。

## 本章节应包含什么 {#what-belongs-here}

Provider Integration 用于记录 Provider 专属认证模式、必填字段、实例配置示例、上游工作流语义、Provider Skill 行为、安全规则和排错步骤。这些内容不应移动到 Core 页面。

## 新增 Provider 文档集 {#adding-a-provider-page-set}

新增 Provider 时至少应包括：概览、安装、认证模式、管理员配置、用户凭证设置、能力地图、主要流程和故障排查。
